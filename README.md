# Telco Customer Churn — Machine Learning Project

## 📌 О проекте

Цель проекта — построить модель машинного обучения для прогнозирования оттока клиентов телекоммуникационной компании.

Используется реальный датасет **IBM Telco Customer Churn**, содержащий информацию о клиентах, подключённых услугах, типах контрактов, способах оплаты и платежах.

**Задача:** бинарная классификация.

**Target:** `Churn`

- `0` — клиент остался
- `1` — клиент ушёл

## 📊 Этапы проекта

В проекте выполнены:

- Exploratory Data Analysis (EDA)
- Очистка и анализ качества данных
- Анализ дисбаланса классов
- Feature Engineering
- `Pipeline` и `ColumnTransformer`
- Logistic Regression baseline
- Decision Tree
- Random Forest
- XGBoost
- Сравнение моделей
- Подбор гиперпараметров с Optuna
- Финальная оценка модели
- Работа с дисбалансом через `class_weight="balanced"`

## 🤖 Сравнение моделей

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.8038 | 0.6485 | 0.5722 | 0.6080 | 0.8359 |
| XGBoost | 0.7918 | 0.6262 | 0.5374 | 0.5784 | 0.8346 |
| Random Forest | 0.7903 | 0.6357 | 0.4947 | 0.5564 | 0.8128 |
| Decision Tree | 0.7306 | 0.4934 | 0.4973 | 0.4953 | 0.6565 |

Лучший результат среди исходных моделей показала **Logistic Regression** с ROC-AUC около **0.836**.

## 🔧 Optuna

Для Logistic Regression был выполнен подбор гиперпараметров с помощью **Optuna (30 trials)** и 5-fold cross-validation.

Лучший ROC-AUC на кросс-валидации составил примерно:

**0.8463**

При этом оптимизированная модель не показала заметного улучшения на отдельной тестовой выборке по сравнению с baseline.

## ⚖️ Дисбаланс классов

Дополнительно была протестирована Logistic Regression с:

`class_weight="balanced"`

Recall для класса оттока увеличился:

**57.22% → 79.68%**

При этом Accuracy снизилась:

**80.38% → 72.57%**

Это показывает компромисс между общей точностью модели и способностью обнаруживать клиентов, которые действительно могут уйти.

## 💡 Вывод

Logistic Regression показала наиболее сбалансированный результат среди протестированных моделей.

Более сложные модели не смогли существенно превзойти baseline. Подбор параметров через Optuna также показал, что улучшение результатов кросс-валидации не обязательно приводит к улучшению качества на тестовой выборке.

Для бизнеса версия с `class_weight="balanced"` может быть полезна, если особенно важно обнаружить как можно больше клиентов с высоким риском оттока.
